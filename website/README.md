# visualmod.vercel.app

Static site (no build step). Deploy this folder with the Vercel CLI:

```
cd website
npx vercel --prod
```

The first time in a new folder, answer "Link to existing project?" with yes and pick the visualmod project.
`downloads/` holds the files the site serves itself (Visual Styles jar and the source ZIPs); launcher and
Visual Client files come from the GitHub release page.
