Discord-Status 

            
            
            

            
Zeigt in Discord z. B. „Playing: mc.hypixel.net“. Der Launcher spricht dafür nur mit der Discord-App auf diesem PC.
              Die Application ID erstellst du unter discord.com/developers
              (New Application → ID kopieren). Optional unter „Rich Presence → Art Assets“ ein Bild mit dem Namen logo hochladen.

          

          

            
Datenschutz

            
Visual Launcher sammelt keine Daten. Es gibt keine Telemetrie, keine Analyse und keinen Server des Entwicklers.
              Der Launcher verbindet sich nur direkt mit Microsoft/Xbox/Mojang (Anmeldung & Spieldateien), Fabric und Modrinth.
