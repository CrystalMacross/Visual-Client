Highlights

What the mod adds

A menu built for speed

The reworked menu shows every module as a card with a switch. Search across all categories as soon as you start typing, open a module's settings with a right click or the gear, and change sliders, colors and modes on one page.

  • Sidebar with categories and module counts
  • Global search: Ctrl + F or just type
  • Prefer the classic menu? Switch under GUI Style → UI: Old / New

Texture Painter

Paint any item's or block's texture pixel by pixel with pencil, fill and undo, and pick colors by HEX code. Your edits stay on after a restart; export them as a ready-to-use resource pack ZIP, including the texture of placed End Crystals.

Pins

Ping a spot like in Fortnite: press J and a flat 2D marker appears where you look, with the distance. Double tap for a red danger pin; off-screen pins wait at the screen edge.

Discord status

The Discord Status module tells Visual Launcher which server you play on and which biome and dimension you are in, so your Discord status shows them with a picture for each biome. It only writes a small file on your PC.

Five menu designs

Pick the menu under GUI Style → UI: Old, New and three modern designs. Glass is a light frosted panel with module cards, Neon a dark neon list whose settings open in place, Spotlight a search-first command palette you can drive with the arrow keys.

Sakura night

The title screen panorama got a new night sky: a milky way full of stars, a glowing moon, warm lanterns, richer cherry blossoms, falling petals and fireflies. Seamless all the way around.

Item Size

Make dropped items bigger or smaller on the ground. Set one size for everything, or open the item editor and give single items their own size.

Shareable configs

Save your settings as named configs and load them again later. Copy a config code to share your whole setup, HUD layout included, with friends.

PvP tools

Shield Status colors shields by whether they can block, Shield Fixes shows the real blocking state, Hit Indicator tells you when a target is in reach, and Totem Tweaks can remove the pop animation.

HUD you can place

Armor, potions, totems, FPS, coordinates, ping, keystrokes and CPS. Arrange it all in the HUD editor.

More FPS, less noise

FPS Boost hides far-away entities and reduces particles. Mute explosions and totem pops, or replace hit and pop sounds with your own choice.

Your sky, your weather

Sky Color paints the sky in any HEX colour, Weather Changer sets the weather on your screen only, Fullbright lights up every cave and Zoom brings far things close on C.

Quality of life

Shulker Tooltips show what is inside a box, Smooth Swap lets items glide between slots, Saturation Overlay shows your hidden hunger and Chat Heads put faces next to messages.

Tune every module

Each module has its own settings page. GUI Style alone lets you choose the UI, square or rounded corners, transparency, font size, accent effects, outlines and glow.

  • Switches, sliders and mode pickers
  • Color picker with HEX input
  • Item editor for per-item sizes
All modules

Every module in the menu

Filter by the menu's categories or search by name. Modules marked HUD also appear in the HUD tab of the menu.

Install

Install the mod by hand

With Visual Launcher none of this is needed: it installs Fabric, Fabric API and the mod for you.

  1. Install Fabric

    Install Fabric Loader for your Minecraft version (1.21.4 – 1.21.11 or 26.1 – 26.3).

  2. Add the files

    Put Fabric API and the Visual Client jar into the mods folder of your game directory.

  3. Start the game

    Launch Minecraft with the Fabric profile. The title screen shows the sakura garden.

  4. Open the menu

    Press Right Shift. You can change the key under Options → Controls.

How it works
Five designs

Pick the look you like

New is the dark HUD with effects and Classic the original look. Since 1.10.10 there are three designs with their own layout: Glass is a light bento dashboard with a floating dock and a round play button, Neon a synthwave arcade with a retro sun, a scoreboard and the navigation at the bottom, Nova an editorial layout with a wide sidebar, serif headlines and a framed cover. Every design has the same functions; switch any time under Settings → Launcher design.

Features

What the launcher does

Microsoft sign-in

Sign in through Microsoft's own window. The launcher never sees your password, supports several accounts and reuses a valid session, so Play starts right away.

Instances

Every instance has its own mods, resource packs and worlds. Fabric, Fabric API and Visual Client are installed automatically. Give each one a profile picture and see its play time.

Modrinth library

Search mods, resource packs, shaders and modpacks, filtered to your instance's version, and install them with one click, dependencies included.

Upload Files

Use mods that are not on Modrinth: add your own .jar mods and .zip resource or shader packs with a button or by drag and drop. The type is detected for you.

Fast start

Sessions, versions and the Java check are cached, game files are checked by size instead of hashing thousands of files, and Java 21+ gets a class cache.

Java handled

The launcher downloads the official Java runtime for each Minecraft version. You can still set your own Java path, memory and JVM arguments.

Your look

Pick a gradient or a solid color by HEX code, or use your own screenshot as the background. Set the accent color, dimming and blur.

Discord status

Shows the server you play on and, with Visual Client, the biome and dimension you are in, with a picture for each biome. Server, biome and world name only if you allow it. It only talks to the Discord app on your PC.

Visual Styles built in

Every Minecraft 1.21.11 instance gets Visual Styles too: press K in game and pick looks for crystals, armor, tools and more. See Styles

Private by design

No telemetry, no analytics and no server of ours. Sign-in tokens stay encrypted on your device and are hidden from the launch log.

How it works

One menu, one Apply

Five menu designs

Studio, Glass (light frosted glass with category pills), Neon (dark glow), Showcase (big preview and a list of looks) and Dock (a drawer at the screen edge, so the game stays visible). Same functions everywhere; switch with the ◐ button or under Extras.

Pick, then Apply

Press K and click styles in as many collections as you like. Press Apply and the game reloads its textures once: everything is on. No resource pack screen, no restart.

Find it fast

Search with /, mark favorites with F, right-click a style for a bigger preview and see the current pick in the preview on the right.

Presets

Three preset slots for your whole look: click a slot to load it, Shift + click to save. Reset puts everything back to vanilla.

Your own styles

The Folder button opens config/visualstyles/custom. A PNG there becomes a style, a folder with Minecraft file names becomes a style with several textures. New files show up in the menu within seconds.

Import your own packs

New in 1.7.0: press Import ZIP, drag .zip packs onto the menu or put them into config/visualstyles/zips. Every pack lands in each category it has textures for, with its own preview picture, and under Whole packs. Older packs (1.12 to 1.21) are converted to the new texture paths.

Extras

Spin speed and core colour of end crystals (HEX), the glow colour of respawn anchor charges, lower fire on your screen and bright titles in dark inventories.

Visual only

Built-in styles are made from the game's own textures, plus looks from 25 texture packs. All of it on your screen only. No advantage over other players: player outlines that would show players through walls are left out on purpose.

Questions

Frequently asked

Can I use Visual Client on servers?

Visual Client is client-side and changes only what you see and hear. Each server decides which mods it allows, so check the server's rules before you join.

Does it cost anything?

No. The mod and the launcher are free.

Is the source code available?

Yes. Visual Client and Visual Launcher are open source under the MIT License. Download the source of both as ZIP files in the download window under “Source code”, or browse it on GitHub.

Do you collect my data?

No. There is no telemetry, no analytics and no server of ours. The launcher talks directly to Microsoft, Mojang, Fabric and Modrinth. Details are in the Privacy policy.

Which key opens the menu?

Right Shift. Zoom is on C, pins are on J. All of them can be changed under Options → Controls.

Can I use mods that are not on Modrinth?

Yes. Open an instance in the launcher and use Upload Files, or drag the .jar onto the instance. Resource and shader packs as .zip work the same way.

How do I switch the launcher design?

Open Settings → Launcher design and choose New, Classic, Glass, Neon or Nova. The launcher reloads in the chosen design and keeps all your settings.

How does the Discord status work?

It is on by default and needs no setup: while the Discord app runs on your PC, Discord shows “Visual Launcher” with your instance and the server you are on, and with Visual Client also the biome and dimension you are in, each with its own picture. The launcher only talks to the Discord app on your PC. Under Settings → Discord you can turn it off or hide the server address, biome or world name.

Does Minecraft close when I close the launcher?

No. The game keeps running, and the launcher counts the play time when you open it again.

Is this an official Minecraft product?

No. Visual Client and Visual Launcher are not approved by or associated with Mojang or Microsoft.

Privacy

Last updated: 24 November 2026

In short: the Launcher and the Mod do not send any data to us. The Visual Client project runs no server, no telemetry, no analytics, no advertising and no automatic crash reports.

1. What is stored on your device

The Launcher keeps the following in its user data folder:

  • Account data: Minecraft name, UUID, skin address, the Microsoft refresh token and the current Minecraft session. The tokens are encrypted with your operating system's key store (Windows DPAPI, macOS Keychain, Linux Secret Service). If your system offers no key store, they are stored there without encryption.
  • Settings: design, colors, background image, memory, window size, Discord settings.
  • Game data: Minecraft, Fabric, Java, instances, mods and worlds.

Tokens are removed from the launch log before it is shown. Signing out, or deleting the user data folder, removes this data completely. The Mod stores its settings and configs in the game's config folder.

2. Services the Launcher contacts

The Launcher connects only to these services, and only when you use the matching feature:

  • Microsoft / Xbox Live (login.live.com, user.auth.xboxlive.com, xsts.auth.xboxlive.com) for sign-in
  • Mojang / Minecraft services (api.minecraftservices.com, piston-meta.mojang.com, launchermeta.mojang.com, libraries.minecraft.net, resources.download.minecraft.net, textures.minecraft.net) for account checks, game files, Java and skins
  • Fabric (meta.fabricmc.net, maven.fabricmc.net) for the mod loader
  • Modrinth (api.modrinth.com, cdn.modrinth.com) for search and downloads
  • The Discord app on your PC (local, only when Discord status is on): the Launcher passes on what you play (instance, Minecraft version and, if enabled, the server address, the biome and dimension, and the world name in singleplayer). Discord shows this to your friends and loads the pictures for the status from this website; Discord's privacy policy applies.

These providers receive technically necessary data such as your IP address, and at sign-in your account data. Their privacy policies apply, for example Microsoft's. We have no access to this data.

3. The Mod

  • Visual Client has no telemetry and sends nothing to us.
  • The Mod does not connect to any online service of its own. Skins, servers and other online features are handled by Minecraft itself.
  • The Discord Status module writes your current server, world name, dimension and biome into a small file in the game folder (visualclient/presence.json) so the Launcher can show them. Nothing is sent anywhere by the Mod; turning the module off deletes the file.
  • Config codes are created on your device. They contain your module settings and HUD layout and go only where you paste them.

4. Minecraft itself

When you start the game, Minecraft processes data under Mojang's and Microsoft's rules, for example for multiplayer, chat reports and the game's own telemetry. This is not part of the Launcher or the Mod.

5. This website (VisualMod.com)

  • This website sets no cookies and uses no analytics, tracking or advertising.
  • This website is hosted by Vercel Inc. (USA). To deliver the page, Vercel processes technically necessary data such as your IP address; Vercel's privacy policy applies.
  • Fonts and images are served from this website itself. The page loads nothing from Google or other third-party services.
  • The launcher and mod files are served by GitHub from the release page of the Visual Client project. GitHub receives technically necessary data such as your IP address, and GitHub's privacy statement applies to those downloads. Visual Styles and the source code ZIPs are served by this website.

6. Your rights

Because we do not receive or store personal data from you, there is nothing we could give you access to or delete. You manage your local data yourself.
